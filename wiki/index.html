Android 应用沙盒

在来宾系统中
运行第三方应用

ASB 在 Android 上模拟一台 32 位 x86 电脑。APK 由来宾 Android 安装和运行，来宾通过模拟的屏幕、磁盘和输入设备交互。

安装第三方应用

  1. 安装 ASB，保持 Android System WebView 已更新。准备含 32 位内核的 Android-x86 ISO。Android-x86 4.4-r2 是 v86 上游记录的测试版本，ASB 安装包不附带系统镜像。
  2. 打开虚拟机，选取 ISO。若要保存安装结果，先创建并选中私有磁盘，再从来宾安装菜单安装到该磁盘。首次测试建议用 512 MiB。
  3. 安装完来宾后弹出启动光盘。在来宾中正常重启，或点击控制台的 Ctrl+Alt+Del。从主磁盘启动后，在文件策略选择「穿透 · 指定一个文件」并选取单个 APK。
  4. Android-x86 自带的终端有 root 权限时，可尝试下方命令。来宾的光驱设备名因镜像而异，先用 ls /dev/block 找到 sr0 或其他光驱节点。未进入 root 终端时，可用来宾自己的文件管理器打开光盘内的 APK，前提是它支持光盘。
mkdir -p /mnt/asb
mount -t iso9660 -o ro /dev/block/sr0 /mnt/asb
pm install /mnt/asb/INPUT.APK
umount /mnt/asb

只有与来宾 Android API 和 ABI 兼容的 APK 才能安装。当前针对 32 位 x86 和无原生库的旧版 APK。需要 ARM 原生库、64 位 ABI、新版 Android、Google Play 服务或图形加速的应用可能无法运行。分包需由来宾提供匹配的安装工具，当前交换光盘一次只承载一个文件。

虚拟设备策略

能力策略实际行为
文件阻止、自定义、指定文件弹出光盘，或将用户给出的内容挂到只读 ISO。应用可以把内容复制到来宾磁盘并写入来宾文件。宿主文件原地读写、自动回写和共享目录尚未接入。
窗口焦点暂停来宾、仅释放输入宿主窗口失焦时停止向来宾发送键鼠事件。默认同时暂停 CPU。第三方应用仍由来宾 Android 决定窗口焦点。
应用列表来宾隔离第三方应用通过来宾 PackageManager 查询来宾自己的包，遵循来宾 Android 的规则。
摄像头、麦克风、网络阻止虚拟机未连接这些宿主设备。摄像头画面注入、联网和每应用规则尚未接入。
录屏来宾系统授权ASB 控制台启用 Android 防截屏。若来宾系统自带录屏，使用其授权和隐私规则。ASB 当前没有专用录屏导出。
Shizuku可选宿主诊断查看服务连接、版本与 UID。虚拟机在未安装 Shizuku 时也可启动。

自定义 ISO 中的 UTF-8 数据使用 INPUT.TXT。现有第三方 APK 可读取它能访问的来宾文件。来宾 Android 框架仍返回自己的系统信息。

磁盘和检查点

临时 RAW 磁盘以源文件为基础运行，来宾写入暂存在本次会话。私有磁盘使用 WebView 的应用专用存储。安装系统后先弹出只读光盘，再点「保存检查点」。检查点包含来宾内存和虚拟磁盘改动，关闭后通过「恢复检查点」继续。直接点击「启动」会重新从基础镜像开机。

当前保留最新的一个检查点。清除 ASB 应用数据会删除私有磁盘和检查点。转译引擎的存档格式发生变化时需要重新安装来宾。运行和保存会使用额外内存和磁盘空间，建议关闭其他高内存应用。

执行模型

  1. 宿主控制台加载随 APK 打包的静态资源。虚拟机没有 Android JavaScript 原生接口和宿主网络设备。
  2. v86 将来宾 x86 指令动态转译为 WebAssembly。Android WebView 执行转译后的代码。模拟器处理来宾发出的设备 I/O，APK 的 Android API 调用则由来宾系统完成。
  3. 虚拟 VGA 承载画面，PS/2 承载键鼠。Android 文件选择器授权的文档经虚拟磁盘或只读光驱进入来宾。虚拟设备规则作用于整台来宾虚拟机。

该方案用于兼容性和隔离实验。转译器、固件和 WebView 属于可信执行链，隔离强度没有经过专门审计。不要把它当作恶意样本分析环境。

构建与签名

npm --prefix vm ci
npm --prefix vm run build
npm --prefix vm test
gradle :app:assembleDebug :app:lintDebug

npm --prefix wiki ci
npm --prefix wiki run build

GitHub Actions 在 main 更新后运行检查。配置好发布密钥后，Actions 使用固定签名打包并发布 ASB-release.apk。Pages 来源设为 GitHub Actions 后，Wiki 会部署到 GitHub Pages。

正式版每天后台检查更新。下载后会核验 SHA-256、包名、递增版本号和 APK 证书，再交给 Android 安装器确认。仓库的 README 包含密钥和 Pages 配置方法。
